# Plus-end elongation with stochastic capping.
#
#   capping_rate   <rate>   plus-end capping rate, 1/time (0 = off)
#   uncapping_rate <rate>   plus-end uncapping rate, 1/time (0 = off)
#
# A cohort seeded together reaches an exponential length distribution with mean
# elongation_rate/capping_rate. Capping blocks plus-end addition; it does not shrink
# a filament, so a capped filament freezes.
#
# smoldyn cappedElongation2D.txt -t
