# Elongation plus capping: the filament-length distribution of a capped population.
#
# A filament grows at elongation_rate until its plus end is capped, which happens as a
# Poisson process at capping_rate. The capping time is therefore Exponential(capping_rate)
# and the length added before capping is
#
#     added length ~ Exponential(mean = elongation_rate / capping_rate)
#
# which is both the biologically expected shape and an exact analytic check on the code.
# Here 0.32 / 4.3 = 0.074, i.e. a mean of ~74 nm, matching the 59 nm (branched) / 108 nm
# (unbranched) median filament lengths measured in situ at mammalian endocytic sites by
# cryo-ET (Serwas et al. 2022, Dev Cell 57:1132).
#
# Filament-type capping keywords:
#   capping_rate   <rate>   plus-end capping rate, per time (default 0 = off)
#   uncapping_rate <rate>   plus-end uncapping rate, per time (default 0 = off)
#
# Setting capping_rate GEOMETRICALLY, as elongation_rate / target length, is deliberate.
# The kinetic route (k_on,CP x [CP] ~ 0.5 /s) predicts ~600 nm filaments, ten times longer
# than the cryo-ET measurement; capping at endocytic sites runs about tenfold faster than
# the bulk capping-protein concentration predicts (Berro et al. 2010).
#
# uncapping_rate is left at 0: capping protein has a ~25-30 min half-life on the barbed
# end (1.3e-4 /s), which is irrelevant over a ~20 s endocytic event. The parameter exists
# for long-timescale network turnover.
#
# LIMITATION worth stating plainly: a capped plus end stops accepting subunits, from
# elongation AND from treadmilling, but the filament does not shrink or disappear. Smoldyn
# has no filament-destruction path, and a vanishing mother would orphan its daughters'
# branch records. A capped treadmilling filament therefore freezes rather than
# depolymerizing away.
#
# Run headless: smoldyn cappedElongation2D.txt -t
# The final dump has one line per filament; contour length is computable from the nodes,
# and the last column before the coordinates is the plus-end capped flag.

graphics opengl_good
