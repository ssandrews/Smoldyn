# Filaments that move with a surface that moves in response to filament forces.
#
# Red filaments grow upward from a floor toward a lid, which has a repel interaction
# with them (surface_interaction lid front all repel 20 2). Since the lid has a
# mobility (mobility 0.2), the growing filaments push it upward. Blue filaments hang
# from the underside of the lid, with their minus ends adsorbed to it (adsorb_node 0
# lid front 0), so they move up with it. The lateral mobility factor of 0 anchors these
# nodes in place on the lid, while the rest of each blue filament swings freely below.
# Green filaments start above the lid and have a reflect interaction with its upper
# face (surface_interaction lid back all reflect), so the lid pushes them upward when it
# reaches them, rather than passing through them. Walls enclose the system, since the
# system boundaries don't affect filaments, and all filaments have a reflect
# interaction with them. The lid is wider than the walls, so that sideways motion
# can't open a gap at its ends. The lid's force and total displacement are listed at
# the end, along with the filaments that have nodes adsorbed to it.
#
# smoldyn movingSurfaceFilaments2D.txt
